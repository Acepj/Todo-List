
# ✅ To-Do App

**Stay Organized, Stay Productive.**

To-Do App is a simple and modern task management website designed to help users organize their daily tasks with ease and clarity. It features a visually appealing landing page with an animated background, responsive design, and a Get Started button that directs users to the main To-Do application.

## 📌 Project Overview

This project is a front-end landing page created using HTML5, Tailwind CSS, and custom CSS animations. The website provides users with a welcoming introduction before accessing the main task management application.

## ✨ Features

- **Responsive Design** – Adapts to different screen sizes, including mobile, tablet, and desktop.
- **Modern Landing Page** – Features a clean and minimal interface with a productivity-focused message.
- **Background Image** – Uses a background image to create a visually engaging appearance.
- **Dark Overlay** – Improves text readability by applying a dark overlay over the background.
- **Animated Blob Background** – Displays a blurred, animated circular background effect.
- **Fade-In Animation** – Adds smooth entrance animations to the heading, description, and button.
- **Get Started Button** – Directs users to the main `todo.html` page.
- **Responsive Typography** – Uses Tailwind CSS responsive text sizes.
- **Hover Effects** – Adds interactive scaling and background color changes to the button.

## 🛠️ Technologies Used

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html`, `todo.html`, and the `images` folder are in the correct locations.
4. Open `index.html` in your browser.
5. You can also use the **Live Server extension** in VS Code.

### Using Live Server

1. Install the Live Server extension in Visual Studio Code.
2. Right-click `index.html`.
3. Select **Open with Live Server**.
4. The landing page will open in your browser.
5. Click the **Get Started** button to access `todo.html`.

## ⚠️ Notes

- This code represents the landing page of the To-Do App.
- The actual task management features should be implemented in `todo.html`.
- Tailwind CSS is loaded using the CDN, so an internet connection is required.
- The background image must be located at `images/todo.jpg`.
- The `todo.html` file must exist for the Get Started button to work.
